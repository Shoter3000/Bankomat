# Bankomat

This project is a banking application developed in NetBeans. It simulates an ATM (Automated Teller Machine) system, providing various functionalities for users to manage their bank accounts.

## Features

- **User Authentication**: Secure login for users to access their accounts.
- **Balance Inquiry**: Check the current balance of the user's account.
- **Cash Withdrawal**: Withdraw cash from the user's account.
- **Deposit Funds**: Deposit cash into the user's account.
- **Account Management**: Manage user account details and settings.

## Getting Started

### Prerequisites

- Java Development Kit (JDK) 1.8 or higher
- Apache Ant 1.8.0 or higher
- NetBeans IDE (recommended for development)

### Installation

1. Clone the repository:
    ```sh
    git clone https://github.com/Shoter3000/Bankomat.git
    cd Bankomat
    ```

2. Open the project in NetBeans IDE.

3. Build the project using Apache Ant:
    ```sh
    ant clean build
    ```

4. Run the project from NetBeans or using the Ant command:
    ```sh
    ant run
    ```

## Usage

1. Launch the application.
2. Log in using your user credentials.
3. Navigate through the menu to access different functionalities:
    - Open bank account
    - Check balance
    - Withdraw cash
    - Deposit funds
    - Manage account settings

## Project Structure

- `src/`: Contains the source code of the application.
- `nbproject/`: NetBeans project files.
- `build.xml`: Ant build script.
- `dist/`: Directory for distribution files (e.g., JAR files).
- `build/`: Directory for build output.
